# Farm animal sound credits

These classroom game clips were adapted from real animal recordings on Wikimedia Commons. Each output is mono AAC audio at 44.1 kHz in an `.m4a` container. The source recordings were shortened, loudness-balanced and given brief edge fades. No creator endorsement is implied.
