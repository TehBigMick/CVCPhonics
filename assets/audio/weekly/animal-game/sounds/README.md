# Farm animal sound files

Add these seven `.m4a` recordings to this folder:

- `dog.m4a`
- `chicken.m4a`
- `cow.m4a`
- `duck.m4a`
- `goat.m4a`
- `pig.m4a`
- `sheep.m4a`

Each file should contain only the corresponding animal call, with little or no silence at the beginning or end.

The game reuses the teacher-recorded page narration in `../../book/pages/` to say the selected animal's name.
